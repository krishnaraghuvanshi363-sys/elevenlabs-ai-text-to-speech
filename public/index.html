💡 How This Application Works (Security Architecture)

1

Frontend (Browser)

User enters text and selects a voice model. On click, sends a clean request to our local Express server.

2

Backend (Secure Proxy)

Express server loads the private ELEVENLABS_API_KEY from .env and calls ElevenLabs API.

3

ElevenLabs AI

ElevenLabs neural network synthesizes speech and streams back raw MP3 audio directly to our player.
